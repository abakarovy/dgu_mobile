## Описание (≤4000 символов)

```
Официальное мобильное приложение ФГБОУ ВО «Колледж ДГУ» для студентов, абитуриентов, родителей и сотрудников. Всё, что нужно для учёбы и взаимодействия с колледжем, собрано в одном месте — без лишних звонков в приёмную и долгих поисков на сайте.

ВОЗМОЖНОСТИ ДЛЯ СТУДЕНТОВ
• Вход и регистрация по ФИО и номеру зачётной книжки, подтверждение по e-mail (OTP).
• Студенческий билет с данными из 1С: группа, курс, отделение, статус.
• Расписание на неделю и пары на сегодня — актуальные данные с портала колледжа.
• Оценки и журнал: текущие отметки, сессия, учебный маршрут (РУП), пропуски.
• Новости колледжа и события.
• Сервисы студента: внешние учебные ресурсы (Юрайт, ПРОФ СПО, Академия Москва), портфолио с загрузкой материалов, стипендиальный рейтинг, объявления отделения, раздел «Студентам» на портале.
• Заявка на настройку пароля Wi-Fi колледжа прямо из приложения.

ДЛЯ РОДИТЕЛЕЙ
• Просмотр данных ребёнка: успеваемость, расписание (в рамках доступа родителя на портале).
• Приглашение родителя по e-mail и статус подключения.

ДЛЯ СОТРУДНИКОВ
• Те же сервисы и справочная информация в рамках роли сотрудника (по политике доступа на портале).

Работает с сайтом college.dgu.ru: данные подтягиваются с сервера колледжа. Часть функций доступна после входа; регистрация и восстановление пароля — на открытом этапе.

Приложение для очного и заочного обучения в СПО. Подходит для ежедневного использования студентами колледжа ДГУ и Республики Дагестан.
```

• E-mail: test@test.ru
• Пароль: test1234
• Вход: экран «Вход по e-mail». OTP не требуется.

Тестовый доступ на прод-сервере (при необходимости запросите у администратора):
• Студент: регистрация (ФИО + номер зачётки 5 цифр) → OTP на e-mail, либо вход по e-mail и паролю.
• Родитель: отдельный вход; для полного теста привязки нужен parent_email в профиле студента на сервере.
• Сотрудник: учётная запись staff/admin по политике бэкенда.

Что проверить:
1. Регистрация и OTP, вход студента.
2. Главная: расписание на сегодня, «Расписание», «Мои задания», «Сервисы студента».
3. Оценки: вкладки «Текущие», «Сессия», «Учебный маршрут».
4. Профиль: студенческий билет, заявка Wi-Fi, приглашение родителя.
5. Push-уведомления (если включены на устройстве).

Ограничения:
• Расписание и оценки на prod зависят от данных 1С на сервере.
• Портфолио: нужны разрешения камеры/файлов на iOS/Android.
• LMS и внешние ссылки открываются в системном браузере, не во встроенном WebView.

Контакт для вопросов проверки: [ваш e-mail], [телефон].
